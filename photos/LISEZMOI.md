# Photos des joueurs

Un fichier par joueur, **nomme par son numero de maillot** :

```
photos/97.jpg     n° 97
photos/6.jpg      n° 6
```

- Format `.jpg`, carre, 400 x 400 px.
- Cadrage sur le visage : l'affichage est circulaire, les coins sont rognes.
- Si la photo manque, l'application affiche les initiales du joueur.

## Source

Le photoshoot officiel du club (dossier Drive « kazma photoshoot », partage le
08/09/2026) : portraits studio sur fond noir, 1080 x 1350, deux poses par
joueur. La pose bras le long du corps a ete retenue ; le recadrage sur le
visage est automatique (le fond noir pur permet de detecter le sommet du crane,
puis la largeur de la tete).

**Ne pas aller chercher des photos de joueurs sur le web** : droits d'auteur et
droit a l'image sur un site publie. Le photoshoot du club est la bonne source.
