# Photos des joueurs

Un fichier par joueur, **nommé par son numéro de maillot** :

```
photos/97.jpg     Drice Chaabi
photos/6.jpg      Abdullah Ghanem
photos/4.jpg      Fahad Al Hajeri
...
```

- Format `.jpg`, **carré**, 400 × 400 px suffit largement.
- Cadrage sur le visage : l'affichage est circulaire, les coins sont rognés.
- Si la photo manque, l'application affiche les initiales du joueur. Rien ne casse.

Les numéros attendus pour l'effectif actuel : 2, 3, 4, 6, 8, 10, 11, 12, 19, 29,
30, 66, 74, 97, 98, 99.
